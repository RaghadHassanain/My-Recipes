# 🍽️ Recipe App (RC-12)

## Description
A fancy React-based recipe search application using Edamam API, styled with Bootstrap.

## Features
- Search recipes by keyword & meal type (breakfast, lunch, dinner)
- View recipe details including ingredients and calories
- Responsive UI using Bootstrap
- Login screen with random background
- Routing between Home, About, Login, and Details pages

## Technologies
- React + Vite
- React Router
- Bootstrap 5
- Axios
- Edamam API

## Installation

```bash
git clone https://github.com/your-username/recipe-app.git
cd recipe-app
npm install
npm run dev
